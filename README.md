# Detección de anomalías con K-Means y PySpark

## Descripción

Proyecto desarrollado durante mi residencia profesional, enfocado en la detección de anomalías en tráfico de red mediante técnicas de Machine Learning y procesamiento distribuido con PySpark.

El proyecto utiliza el dataset KDD Cup 1999, empleado para el análisis de tráfico de red y la identificación de comportamientos potencialmente anómalos.
El dataset puede ser descargado de kaggle: https://www.kaggle.com/datasets/galaxyh/kdd-cup-1999-data/data?select=kddcup.data.gz

## Tecnologías utilizadas

- Python
- PySpark
- K-Means
- NumPy
- Matplotlib

## Desarrollo del proyecto

El proyecto contempla:

Carga y procesamiento distribuido de los registros mediante PySpark.
Separación de características y etiquetas a partir de los datos originales.
Transformación de las características a vectores numéricos.
Estandarización de las variables para preparar los datos para K-Means.
Agrupamiento de los registros mediante K-Means.
Análisis de la variabilidad y características de los grupos obtenidos.
Identificación de registros considerados potencialmente anómalos.
Visualización y análisis de los resultados obtenidos.

## Dataset

Se utilizó el dataset **KDD Cup 1999**, un conjunto de datos utilizado para el análisis de tráfico de red y detección de intrusiones.
